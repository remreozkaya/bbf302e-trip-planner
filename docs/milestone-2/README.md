# Milestone 2 — ER Diagram and Data Model Design

**Team:** The Boyz - Trip Planner
**Project:** Group Travel Expense & Activity Planner

## Overview

This milestone presents the database design for managing group trips, memberships, activities, reservations, shared expenses, and settlements.

## Files

- `Milestone2.pdf` — Milestone 2 report.
- `ER_Diagram.drawio` — Editable ER diagram; open with diagrams.net.
- `ER_Diagram.png` — Exported ER diagram for viewing.

## Report Contents

- Entities, relationships, and cardinalities.
- Relational table schemas, attributes, keys, and data types.
- Data requirements and population plans.
- Planned CRUD operations.
- Complex query scenarios.
- Team responsibilities and changes from Milestone 1.

## Scope

This milestone covers database design and implementation planning. SQL implementation and application development belong to subsequent milestones.
